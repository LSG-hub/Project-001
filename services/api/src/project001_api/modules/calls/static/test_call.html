      How this works
      
Your mic audio goes to the API as 16 kHz PCM over a WebSocket (/v1/calls/test). The API streams it
      to Gemini Live on Vertex AI and sends back the assistant's voice (24 kHz PCM) plus events: transcript fragments for
      both sides, interrupted when you talk over it, turn_complete, and tool_call
      when it uses a function like end_call. When the call ends, Gemini writes the summary from the transcript.
